# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии следуют [семантическому версионированию](https://semver.org/lang/ru/).

## [0.4.0] — 2026-11-10

Релиз посвящён фоновой работе, прозрачности учёта и защите данных от подмены.

### Добавлено

- **Трей.** Меню «Открыть», «Пауза учёта», «Выход»; левый клик открывает окно.
- **Автозапуск с Windows** через `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
  без прав администратора; путь перезаписывается при каждом включении.
- **Скрытый старт** и поведение крестика и кнопки «свернуть» настраиваются.
- **Экран настроек**: 15 параметров, мгновенное сохранение, каждая опция
  подключена к реальному поведению.
- **История сессий**: список, добавление задним числом (1–1440 минут, не в
  будущее), удаление, сброс статистики игры.
- **Параметры запуска**: аргументы командной строки и рабочая папка на игру.
- **«Обновить exe»** — пересчёт хеша и иконки после обновления игры.
- **Настоящие иконки exe** через `SHGetFileInfoW` и `IImageList` с кэшем в `icons/`.
- **Темы**: графит, полночь, OLED; режим уменьшенных анимаций.
- **Экспорт и импорт** подписанной резервной копии данных.
- **Подпись данных** HMAC-SHA256 для пяти файлов состояния, канонизация ключей.
- **Строгий режим**: учёт только для exe с совпадающим хешем, запущенного
  лаунчером, с видимым окном.
- **Обнаружение перевода часов** по подписанной отметке `last_seen`.
- **Предупреждения** о повреждённых файлах в интерфейсе.

### Изменено

- Длительность сессии считается монотонным таймером; системные часы
  используются только для отображения.
- Версия синхронизирована во всех манифестах: 0.4.0.
- README переработан, добавлены юридические документы и скриншоты.

### Исправлено

- Чип «идёт» больше не растягивался на всю карточку из-за конфликта селекторов.
- Формы запуска и добавления сессии не закрываются при ошибке валидации.
- После пересчёта хеша иконка игры обновляется без перезапуска.
- Сегменты тем получили корректное состояние `aria-pressed`.

### Безопасность

- Изменение подписанных файлов вне программы обнаруживается; испорченный файл
  сохраняется как `*.tampered.bak` вместо тихого принятия.
- Проверка PE-заголовка, размера и имени exe; запрет `%WINDIR%` и самого
  лаунчера; чёрный список системных утилит.

## [0.3.0] — 2026-11-09

### Изменено

- Переработан интерфейс на React 19 с системой движения.
- Персист сессий и локальное время в статистике.
- Файловые операции вынесены за пределы блокировок.

### Исправлено

- Дедлок при одновременном запуске игры и обновлении состояния.
- Находки ревью по обработке ошибок и граничным случаям.

## [0.2.0] — 2026-11-08

### Добавлено

- Движок сессий и достижений, разработанный через тесты.
- Атомарное хранилище JSON (временный файл и переименование).
- Достижения как данные: условие описывается JSON, а не кодом.
- Витрина-сетка, сцена пустого экрана, график недели, экран достижений.
- Предпросмотр интерфейса в браузере без ядра.

## [0.1.0] — 2026-11-07

### Добавлено

- Первый рабочий каркас: Tauri 2, Rust-трекер часов, библиотека игр.
- Ночная палитра «графит и золото», иконка-полумесяц.
- CI: тесты и сборка exe с NSIS-установщиком.
