# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной версии.
Более ранние версии не поддерживаются.

| Версия | Поддержка |
| --- | --- |
| 0.4.x | Да |
| 0.3.x и ниже | Нет |

## Как сообщить об уязвимости

Не создавайте публичный issue для уязвимостей. Используйте приватный канал:

1. **GitHub Security Advisories** — вкладка *Security → Report a vulnerability*
   в репозитории <https://github.com/Ventaxis/nyxlauncher>.
2. Если канал недоступен, создайте issue без технических деталей и попросите
   связаться приватно.

В обращении укажите: версию ПО, версию Windows, шаги воспроизведения,
последствия и, при наличии, предложение по исправлению.

**Сроки.** Подтверждение получения — до 5 рабочих дней. Первичная оценка — до
10 рабочих дней. Публичное раскрытие — по согласованию, обычно после выпуска
исправления.

**Safe harbor.** Мы не будем преследовать исследователей, действующих
добросовестно: не наносящих ущерб, не затрагивающих чужие данные и не
раскрывающих проблему до согласованной даты.

## Модель угроз

NyxLauncher — локальное приложение без серверной части. Это определяет, что оно
может и чего не может защищать.

### Что защищается

- **Целостность данных.** `games.json`, `sessions.json`, `achievements.json`,
  `settings.json` и `meta.json` подписаны HMAC-SHA256. Изменение файла вне
  программы обнаруживается при следующей загрузке: файл уводится в
  `*.tampered.bak`, а в интерфейсе появляется предупреждение.
- **Подмена исполняемых файлов.** При добавлении игры проверяется PE-заголовок,
  минимальный размер, имя и расположение файла; вычисляется SHA-256. В строгом
  режиме запуск засчитывается только при совпадении хеша и наличии видимого окна
  процесса, порождённого лаунчером.
- **Манипуляция системными часами.** Длительность сессии считается по
  монотонному таймеру, а перевод часов назад выявляется по подписанной отметке
  `meta.last_seen` с допуском 300 секунд.
- **Накрутка «пустышками».** Процесс без видимого окна с непустым заголовком не
  засчитывается.

### Что не защищается

- **Локальный администратор.** Пользователь с правами администратора владеет и
  файлами, и ключом подписи, и процессом. Он может удалить данные, откатить
  состояние или собрать собственную сборку. HMAC здесь — средство обнаружения
  изменений, а не защиты от владельца устройства.
- **Абсолютная защита игрового времени.** Любая локальная метрика поддаётся
  фальсификации на машине, где она вычисляется. Гарантировать «невозможность
  накрутки» технически нельзя; можно лишь сделать её заметной и неудобной.
- **Сторонние античит-системы.** ПО не является античитом, не внедряется в
  процессы игр, не перехватывает трафик и не обходит защиты. Ответственность за
  соблюдение пользовательских соглашений игр лежит на пользователе.

## Поверхность атаки

| Компонент | Риск | Мера |
| --- | --- | --- |
| Чтение путей и иконок exe | специально сформированный файл | проверка PE-заголовка и размера, отказ для `%WINDIR%` и системных утилит |
| Импорт резервной копии | подмена данных | проверка HMAC-подписи, отказ при несовпадении |
| Автозапуск | подмена команды в реестре | запись только в `HKCU`, значение перезаписывается при каждом включении |
| Трей и окно | случайное скрытие окна | окно создаётся скрытым и показывается по явному действию пользователя |
| Сетевые функции | отсутствуют | ПО не инициирует сетевых соединений |

## Проверка целостности релиза

Каждый релиз содержит файл `SHA256SUMS.txt`. Проверка в PowerShell:

```powershell
Get-FileHash .\NyxLauncher_0.4.0_x64-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

Хеши должны совпасть. Сборки создаются публичным workflow GitHub Actions из
тегированного коммита; журнал сборки доступен во вкладке Actions.

## Подпись кода

Установщик не подписан сертификатом Authenticode: проект распространяется
бесплатно и не имеет коммерческого сертификата подписи. Windows SmartScreen
может показать предупреждение «Неизвестный издатель». Проверяйте хеш по
`SHA256SUMS.txt` и скачивайте файлы только из раздела Releases официального
репозитория.
