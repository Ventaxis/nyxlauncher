## Порядок применения

1. Установка или запуск программы означает принятие [LICENSE](../../LICENSE).
2. Установщик показывает текст лицензии перед установкой.
3. При распространении неизменённых официальных сборок сохраняются
   [LICENSE](../../LICENSE) и [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).

## Важное уведомление

Документы составлены по общепринятым образцам и описывают фактическое поведение
программы на момент версии 0.4.0. Они не являются юридической консультацией.
Перед коммерческим использованием, распространением через магазины приложений
или изменением модели распространения рекомендуется проверка документов
юристом соответствующей юрисдикции.

## Изменения

Актуальная редакция всегда находится в репозитории. Существенные изменения
