# Политика конфиденциальности NyxLauncher

Документ описывает, какие данные обрабатывает NyxLauncher, где они хранятся и
как их удалить. Редакция от 10 ноября 2026 года, версия ПО 0.4.0.

## 1. Кратко

- NyxLauncher работает полностью локально и **не инициирует сетевых соединений**.
- Нет учётных записей, телеметрии, аналитики, рекламы и облачной синхронизации.
- Все данные лежат в одном каталоге на вашем компьютере и принадлежат вам.
- Правообладатель не получает доступа к вашим данным и не может их прочитать.

## 2. Кто обрабатывает данные

Обработку данных на вашем устройстве выполняет само программное обеспечение
NyxLauncher. Правообладатель (Ventaxis Corp) не выступает оператором этих
данных, поскольку не получает к ним доступа.

## 3. Какие данные хранятся локально

| Файл | Содержимое |
| --- | --- |
| `games.json` | название игры, путь к exe, аргументы запуска, рабочая папка, SHA-256 exe, дата добавления |
| `sessions.json` | сессии: идентификатор игры, начало, конец, длительность, признак ручной правки |
| `achievements.json` | условия достижений и даты их открытия |
| `settings.json` | настройки интерфейса, трекинга и автозапуска |
| `meta.json` | случайный идентификатор установки, время последней активности, отметки о повреждённых файлах |
| `secret.bin` | локальный ключ HMAC для проверки целостности данных |
| `icons/` | кэш иконок исполняемых файлов в PNG |

Дополнительно в реестре Windows создаётся значение
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\NyxLauncher` — только если
вы включили автозапуск. Оно содержит путь к exe и аргумент `--minimized`.

Каталог данных: `%APPDATA%\corp.ventaxis.nyxlauncher`.

## 4. Что ПО читает во время работы

- список процессов и их исполняемые файлы — чтобы определить, запущена ли игра;
- заголовки и видимость окон процессов из библиотеки — чтобы не считать
  фоновые процессы и «пустышки»;
- PE-заголовок и размер exe при добавлении игры — чтобы отклонить служебные и
  системные утилиты;
- иконку exe через системный API оболочки Windows.

Эти данные не покидают устройство и не сохраняются, за исключением перечисленных
в разделе 3.

## 5. Чего ПО не делает

- не отправляет статистику, журналы и идентификаторы на серверы;
- не собирает сведения об оборудовании, учётной записи Windows или геолокации;
- не внедряется в процессы игр и не перехватывает их трафик;
- не устанавливает сторонние компоненты и не изменяет системные настройки,
  кроме значения автозапуска, включаемого вами;
- не содержит рекламных и аналитических модулей.

## 6. Передача данных третьим лицам

Правообладатель не передаёт данные третьим лицам, так как не располагает ими.
При обращении в поддержку через GitHub вы самостоятельно публикуете те сведения,
которые решите указать; их обработка регулируется политикой GitHub.

## 7. Срок хранения и удаление

Данные хранятся, пока вы их не удалите. Способы удаления:

1. удалить отдельные игры и сессии в интерфейсе;
2. очистить статистику в настройках;
3. удалить каталог `%APPDATA%\corp.ventaxis.nyxlauncher` целиком;
4. удалить программу через «Установка и удаление программ».

Экспорт и импорт создают подписанную копию данных в выбранном вами файле. Такой
файл содержит ту же информацию и должен храниться так же бережно, как и каталог
данных.

## 8. Безопасность

Данные подписываются локальным ключом HMAC-SHA256, что позволяет обнаружить
изменение файлов вне программы. Ключ хранится рядом с данными и не является
средством защиты от администратора устройства. Подробнее — в
[SECURITY.md](../../SECURITY.md).

## 9. Дети

ПО не предназначено для сбора данных о детях и не собирает персональные данные
вообще. Несовершеннолетние используют ПО с согласия законных представителей.
